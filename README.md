# Help-Caple

・README
・Help-Caple.stl

これは、ヘルプマークのためのケースです。
「ヘルプマーク」だけでは、所有者が"何を求めているかわからない"といった問題がありました。
「ヘルプメッセージ」だけでは、目立たず"周囲に気づいてもらえない"といった問題がありました。
上記の問題から、「ヘルプマークとヘルプメッセージを必要な時だけ、両方表示できるケースが欲しい」といった声がありました。
そこで、私はこの「ヘルプキャップル」と名付けた専用のケースを設計しました。
このケースは、3Dプリンタで造形することを想定して設計しているので、サポータや組み立てが不要です。
「Print-in-Place」と呼ばれる手法で、組み立てられた状態で造形できます。
帽子のように装着しやすく、ヘルプマークもヘルプメッセージの片方が欠けると成り立たなくなることから、「cap」と「couple」を合わせて「Help-Caple」と命名しました。
